# Student Performance Analysis

## Project Overview
This project analyzes student academic performance using Python. It calculates average marks, determines pass/fail results, and visualizes student performance using charts.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## Features
- Reads student marks from a CSV file.
- Calculates average marks for each student.
- Determines pass/fail status based on subject marks.
- Displays subject-wise average marks.
- Generates student comparison charts.
- Calculates the overall pass percentage.

## Project Files
- `analysis.py` — Main Python program.
- `students.csv` — Student marks dataset.
- `subject_analysis.png` — Subject-wise average marks chart.
- `student_comparison.png` — Student performance comparison chart.

## Requirements
Install the required Python libraries:

```bash
python -m pip install pandas matplotlib
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

```bash
python analysis.py
```

4. View the generated performance charts and report.
